# We Bookoholicx

We Bookoholicx is a beginner-level web application project designed to help understand how a basic web app with multiple pages works. This project enables users to **purchase, sell, and exchange books** with other users in close proximity. Developed using **HTML, CSS, and JavaScript**, the platform serves as a hands-on learning experience for web development fundamentals and book community building.

## Features

- **Multi-Page Navigation:** Experience the structure and flow of a real web app with several interconnected pages.
- **Book Exchange:** Swap books with other members in your local area, making it easy and economical to explore new reads.
- **Buy & Sell Books:** Purchase books directly from other users or list your own for sale.
- **Read Summaries:** Access summaries of popular books to help you decide your next read.
- **Audio Books:** Listen to embedded audio versions of select books directly on the platform.
- **Location Services:** Find users and exchanges near you via an integrated map.
- **Community Integration:** Join our WhatsApp group to interact and coordinate exchanges.
- **Simple User Forms:** Practice building and handling basic HTML forms for membership and payments.
- **Responsive UI Elements:** Uses Bootstrap and custom CSS to explore layout, styling, and user interface patterns.

## Learning Highlights

- Understanding **HTML structure** and page linking for multi-page sites.
- Applying **CSS and Bootstrap** for layout, color, and design.
- Integrating **basic JavaScript** for interactivity (e.g., prompts, navigation).
- Embedding external resources like maps and YouTube videos.
- Building **simple forms** for user data collection and payment simulation.
- Managing a basic project directory and assets (images, stylesheets, etc.).
- Practicing community features and basic user engagement.

## Project Structure

- `index.html` – Home page with navigation and introduction.
- `books.html` – Browse available books.
- `exchange.html` – Book exchange options and community links.
- `audio book.html` – Listen to audio summaries of popular books.
- `loction.html` – Find exchanges and users near you via map integration.
- `about us.html` – Learn more about the team and mission.
- `payment form.html` – Membership and payment details.
